# Competitive Landscape (Snapshot)

AutoSave sits at the intersection of:
- DCA / recurring buy tools
- LP management & auto-compounders
- General DeFi automation / agent frameworks on Solana

### Related Categories
- Pure DCA products (e.g. various Solana DCA bots and interfaces)
- LP managers and yield optimizers
- Agent kits and automation frameworks (Solana Agent Kit, visual workflow builders, etc.)
- Broader DeFi dashboards with limited automation

### Differentiation Goals
AutoSave aims to win on:
1. **Unified experience** — Savings + DCA + LP + Fee management in one coherent product
2. **Simplicity** — Feels like a modern savings/automation app rather than a power-user terminal
3. **Opinionated defaults** with progressive disclosure of advanced controls
4. **Strong non-custodial guarantees** and transparent execution

Exact competitive positioning will be refined as the product takes shape.
